How I deliver

A transparent process so the first project feels low-risk.

  1. Short brief Goal, references, deadline, budget. No mandatory one-hour call.
  2. Fixed quote + deposit We lock the scope. I work via escrow or upfront deposit.
  3. Draft → revisions → ship You get a working preview. 1–2 revision rounds inside the brief.
  4. Handoff Access, a short edit guide, and how to update content yourself.
